# 基于深度学习的微博舆情分析系统

## 一、项目简介

本项目是一个基于深度学习的微博舆情分析系统，面向微博文章和评论数据，实现数据采集、数据处理、舆情统计、热点词分析、可视化展示以及文本情感分析等功能。

本系统作为本科毕业设计项目，旨在利用自然语言处理和深度学习技术，对微博平台中的用户观点和舆论倾向进行分析，为网络舆情监测和信息研判提供参考。

## 二、系统功能

### 1. 用户管理

- 用户注册与登录
- 用户身份验证
- 用户退出登录
- 基于登录状态访问系统功能

### 2. 微博数据采集

- 采集微博文章及相关评论数据
- 获取文章标题、正文、发布时间、作者等信息
- 获取评论内容、评论用户及评论来源等信息
- 将采集结果保存为 CSV 文件

### 3. 数据清洗与数据库存储

- 对微博文章和评论数据进行整理
- 清理重复数据和无效数据
- 将处理后的数据保存到 MySQL 数据库
- 支持文章数据和评论数据的持久化管理

### 4. 舆情数据统计

- 统计微博文章数量
- 统计微博评论数量
- 分析文章发布趋势
- 统计文章类型及其数量
- 分析高频发言用户
- 统计评论来源地区及 IP 分布
- 展示点赞量较高的微博文章

### 5. 热词分析与词云展示

- 使用 Jieba 对微博文章和评论进行中文分词
- 去除停用词、数字和无意义词语
- 统计文章和评论中的高频词
- 展示微博舆情热点词语
- 生成文章词云和评论词云
- 支持根据关键词查看相关统计信息

### 6. 评论情感分析

- 对微博文本和评论内容进行情感分类
- 将文本划分为正面、负面和中性情感
- 输出情感预测结果及置信度
- 结合统计图表展示整体舆情倾向

## 三、使用的模型

本项目的情感分析模块采用 **BERT-BiLSTM 深度学习模型**。

### 1. BERT

BERT 用于提取微博文本的上下文语义特征。与传统词袋模型和普通词向量相比，BERT 能够结合上下文理解词语在不同语境中的含义，适合处理微博文本中存在的口语化、简短化和语义复杂等问题。

### 2. BiLSTM

在 BERT 输出的文本特征基础上，使用双向长短期记忆网络（BiLSTM）进一步建模文本序列信息。BiLSTM 可以同时利用前向和后向的上下文信息，更好地捕捉评论文本中的情感表达和语义依赖关系。

### 3. 分类层

经过 BERT 和 BiLSTM 特征提取后，模型通过 Dropout 层和全连接分类层输出情感类别。当前系统支持正面和负面二分类，并根据预测置信度补充中性判断。

模型结构概括如下：

```text
输入文本
   ↓
BERT 分词与上下文特征提取
   ↓
双向 LSTM（BiLSTM）
   ↓
Dropout
   ↓
全连接分类层
   ↓
情感类别与置信度
```

## 六、运行说明

### 1. 安装依赖

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\Activate.ps1
```

安装项目依赖：

```bash
pip install -r requirements.txt
```

### 2. 准备模型文件

请将本地 BERT 预训练模型放在以下项目目录中：

```text
models/BERT1/
```

如需启用情感分析功能，还需要将训练好的权重文件放在：

```text
saved_models/best_model.pth
```

模型权重文件较大，已从项目中删除，并通过 `.gitignore` 忽略，不建议直接提交到 GitHub 普通仓库。

### 3. 配置数据库

创建 MySQL 数据库，并根据本地环境修改数据库连接配置。数据库名称默认为：

```text
db_weibo3
```

请不要将真实数据库密码、Cookie 或其他隐私信息提交到公共代码仓库。

### 4. 启动系统

在项目根目录执行：

```bash
python app.py
```

启动后访问：

```text
http://127.0.0.1:5000/user/login
```

## 八、注意事项

1. 项目中的路径均基于项目目录自动计算，避免依赖特定电脑的绝对路径。
2. BERT 模型文件和训练权重文件需要用户自行准备。
3. `saved_models/best_model.pth` 文件超过 GitHub 单文件 100 MB 限制，因此不纳入 Git 版本管理。
4. 使用爬虫功能时应遵守微博平台的相关规定，不得进行影响平台正常运行的操作。
5. 数据库用户名、密码和爬虫配置应根据实际运行环境修改。

## 九、毕业设计说明

本系统综合运用了 Web 开发、数据库技术、数据采集、中文文本处理、数据可视化和深度学习等知识，完成了从微博数据采集到舆情分析结果展示的完整流程。系统以 BERT-BiLSTM 模型为核心，实现了面向微博文本的情感分析，为网络舆情分析系统的设计与实现提供了一个实践案例。
